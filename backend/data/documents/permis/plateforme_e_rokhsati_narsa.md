## Présentation

Le permis de conduire est un document obligatoire pour conduire un véhicule.

Il existe neuf catégories de permis de conduire.

Chaque catégorie permet de conduire un type déterminé de véhicule.

Les éléments suivants peuvent varier selon la catégorie :

- âge légal ;
- conditions d’accès ;
- démarches administratives ;
- justificatifs demandés ;
- type de véhicule autorisé.

## Services disponibles

### Création d’une demande

La plateforme permet de créer une demande en ligne liée au permis de conduire.

Elle peut notamment concerner :

- l’échange du permis en cas de dégradation ;
- le changement d’identité ;
- le renouvellement du permis.

La plateforme guide le demandeur dans les différentes étapes de la procédure.

### Suivi d’une demande

L’utilisateur peut suivre l’avancement de sa demande à l’aide de ses informations d’identification.

Les informations demandées peuvent inclure :

- le numéro d’identité ;
- le numéro du permis de conduire.

Le suivi permet de consulter l’état actuel du traitement de la demande.

### Impression de documents

La plateforme permet d’imprimer certains documents associés à une demande.

Elle peut notamment permettre l’impression d’un permis provisoire, selon l’état de traitement du dossier.

## Fonctionnement général

1. Accéder à la plateforme e-Rokhsati.
2. Choisir le service souhaité.
3. Créer ou consulter une demande.
4. Saisir les informations d’identité et les informations du permis.
5. Suivre l’état d’avancement.
6. Imprimer les documents disponibles lorsque le service le permet.
