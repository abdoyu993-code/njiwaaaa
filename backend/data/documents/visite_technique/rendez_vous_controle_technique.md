## Présentation

Le contrôle technique est un contrôle réglementaire effectué périodiquement.

Il vise à vérifier que les véhicules respectent les normes de sécurité routière et les exigences environnementales applicables.

## Étapes de prise de rendez-vous

La procédure de rendez-vous présentée sur la plateforme comprend les étapes suivantes :

1. fournir les informations relatives à la visite technique ;
2. choisir le centre de contrôle technique ;
3. renseigner les informations du client ;
4. sélectionner une date et une heure disponibles ;
5. confirmer le rendez-vous.

## Informations demandées

La plateforme peut demander notamment :

- le type de véhicule ;
- le type de visite ;
- le centre souhaité ;
- les informations du propriétaire ou du client ;
- la date ;
- l’heure du rendez-vous.

## Choix du centre

Le demandeur doit choisir un centre de visite technique disponible.

Il est recommandé de vérifier que le centre sélectionné est agréé pour effectuer le type de contrôle demandé.

## Types de demandes possibles

La plateforme peut permettre notamment :

- la prise de rendez-vous ;
- la recherche du centre le plus proche ;
- le dépôt d’une réclamation ;
- l’envoi d’un avis.

## Avertissement sur la source

Cette plateforme constitue une source complémentaire pour la prise de rendez-vous.

Pour les règles officielles concernant :

- la périodicité ;
- les véhicules concernés ;
- les documents obligatoires ;
- les tarifs ;
- la contre-visite ;
- les centres agréés ;

les informations doivent être confirmées à partir des documents officiels de la NARSA ou du ministère chargé du Transport.
