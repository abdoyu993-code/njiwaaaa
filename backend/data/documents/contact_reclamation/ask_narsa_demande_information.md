# ASK NARSA — Demande d’information

## Métadonnées

- Domaine : contact_reclamation
- Intentions concernées :
  - demande_information
  - contact_narsa
  - suivi_demande
  - droit_acces_information
- Organisme : Agence Nationale de la Sécurité Routière — NARSA
- Source : ASK NARSA et NARSA Services
- URL : https://www.asknarsa.ma/
- Langues : français et arabe
- Pays : Maroc

## Présentation

ASK NARSA est un espace permettant à l’usager de :

- soumettre une demande d’information ;
- suivre une demande déjà déposée ;
- exercer son droit d’accès à l’information ;
- conserver une référence de suivi.

## Nouvelle demande

Pour déposer une demande, l’usager doit généralement :

1. accéder à la plateforme ASK NARSA ;
2. choisir l’option de nouvelle demande ;
3. renseigner les informations demandées ;
4. expliquer précisément l’information recherchée ;
5. envoyer la demande ;
6. conserver le numéro ou la référence de suivi.

## Contenu recommandé

La demande doit être :

- claire ;
- précise ;
- limitée à une question identifiable ;
- liée aux activités de la NARSA ;
- accompagnée des informations utiles à son traitement.

## Suivi

Après le dépôt, l’usager peut utiliser le système de suivi mis à disposition par la plateforme.

Il doit conserver :

- le numéro de demande ;
- l’adresse électronique utilisée ;
- le numéro de téléphone utilisé ;
- les éventuels messages reçus.

## Différence entre information et réclamation

ASK NARSA sert principalement à demander une information.

Une réclamation concerne plutôt :

- un dommage ;
- une difficulté liée à un service public ;
- un comportement administratif contesté ;
- une absence de traitement ;
- un problème nécessitant une réponse administrative formelle.

Dans ce dernier cas, le portail Chikaya peut être utilisé.
