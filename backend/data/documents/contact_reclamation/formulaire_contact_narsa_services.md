# Formulaire de contact NARSA Services

## Métadonnées

- Domaine : contact_reclamation
- Intentions concernées :
  - contact_narsa
  - demande_information
  - assistance_service
  - probleme_plateforme
- Organisme : Agence Nationale de la Sécurité Routière — NARSA
- Source : NARSA Services
- URL : https://khadamatnarsa.ma/fr/form/contact
- Langues : français et arabe
- Pays : Maroc

## Présentation

Le formulaire de contact de NARSA Services permet à l’usager de transmettre une demande par voie électronique.

## Utilisations possibles

Le formulaire peut être utilisé notamment pour :

- demander une information ;
- signaler un problème lié au portail ;
- demander une orientation vers un service ;
- signaler une difficulté rencontrée pendant une démarche ;
- poser une question générale sur un service NARSA.

## Informations à préparer

Avant d’envoyer une demande, l’usager doit préparer :

- son identité ;
- ses coordonnées ;
- l’objet de sa demande ;
- une description claire du problème ;
- les références du dossier lorsqu’elles sont nécessaires ;
- les pièces justificatives non sensibles, lorsque le formulaire les autorise.

## Rédaction recommandée

La demande doit préciser :

1. le service concerné ;
2. la démarche effectuée ;
3. la date du problème ;
4. le message ou l’erreur rencontrée ;
5. le résultat attendu ;
6. les moyens de contacter le demandeur.

## Vérification anti-spam

Le formulaire peut demander une vérification permettant de confirmer que la soumission est réalisée par une personne et non par un programme automatique.

## Attention

Le formulaire de contact général ne remplace pas toujours :

- une réclamation officielle ;
- un recours administratif ;
- une déclaration d’infraction ;
- une demande de duplicata ;
- une démarche nécessitant un formulaire réglementaire.

Pour une réclamation administrative formelle, le portail Chikaya peut être plus approprié.
