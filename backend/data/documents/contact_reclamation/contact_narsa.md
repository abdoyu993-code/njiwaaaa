## Types de demandes

Le citoyen peut contacter la NARSA pour :

- demander une information générale ;
- être orienté vers un service ;
- connaître une procédure ;
- obtenir les coordonnées d’un service ;
- signaler une difficulté ;
- demander des informations relatives aux services numériques.

## Information importante

Pour une procédure spécifique, le citoyen doit utiliser le service numérique correspondant lorsque celui-ci existe :

- ASK NARSA pour une demande d’information ;
- KHADAMAT NARSA pour certaines démarches et suivis ;
- Chikaya pour une réclamation administrative ;
- la plateforme Infractions Routières pour les contraventions ;
- le portail de mutation pour la vente ou l’achat d’un véhicule.

## Protection des informations personnelles

Les informations sensibles telles que les numéros de documents officiels ne doivent pas être envoyées par un canal non sécurisé sans vérification.
