- Source : NARSA Services

- Langues : français et arabe
- Pays : Maroc

## Présentation

Le service de suivi des dossiers permet à l’usager de consulter l’avancement de certaines demandes traitées par la NARSA.

## Dossiers pouvant être concernés

Selon le service utilisé, le suivi peut notamment concerner :

- un permis de conduire ;
- un duplicata ;
- un renouvellement ;
- une carte grise ;
- une immatriculation ;
- une mutation ;
- une autre démarche disponible sur KHADAMAT NARSA.

## Informations à conserver

Après le dépôt d’un dossier, l’usager doit conserver :

- le récépissé de dépôt ;
- le numéro du dossier ;
- le numéro de demande ;
- les références du document concerné ;
- les SMS reçus ;
- la date et le lieu du dépôt.

## Consultation

Pour effectuer un suivi :

1. accéder à la page de suivi ;
2. saisir les informations demandées ;
3. vérifier l’état du dossier ;
4. consulter les éventuelles indications complémentaires ;
5. attendre la notification lorsqu’un document est prêt.

## Notification

Pour certaines démarches, la NARSA envoie un SMS lorsque le nouveau document peut être récupéré.

## En cas d’absence de résultat

Lorsque la plateforme ne retourne aucun dossier, l’usager doit vérifier :

- l’exactitude du numéro saisi ;
- l’identité saisie ;
- le numéro du permis ou de la carte grise ;
- la date du dépôt ;
- le service utilisé ;
- le délai écoulé depuis le dépôt.

Il peut ensuite contacter le point de dépôt ou la NARSA.

## Précaution

Le citoyen ne doit pas communiquer publiquement :

- son numéro de carte nationale ;
- son numéro complet de dossier ;
- son numéro de permis ;
- des copies de documents sensibles.
