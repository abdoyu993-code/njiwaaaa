## Présentation

Chikaya est le portail national permettant aux usagers de communiquer avec les administrations publiques.

Il permet notamment de :

- soumettre une réclamation ;
- suivre une réclamation ;
- soumettre une observation ;
- soumettre une suggestion.

## Quand déposer une réclamation ?

Une réclamation peut être déposée lorsque l’usager :

- rencontre une difficulté pendant l’utilisation d’un service public ;
- subit un préjudice lié à une décision ou à un comportement administratif ;
- estime qu’une pratique est contraire à la loi ;
- estime qu’un traitement est contraire aux principes de justice ou d’équité ;
- ne reçoit pas de réponse adaptée.

## Observation

Une observation concerne la manière dont un service public a été fourni.

Elle peut porter sur :

- l’accueil ;
- le délai ;
- l’organisation ;
- la qualité du service ;
- la clarté des informations ;
- le comportement rencontré.

## Suggestion

Une suggestion permet de proposer une idée destinée à améliorer les services publics.

## Étapes de dépôt

Le fonctionnement général est le suivant :

1. choisir l’administration concernée ;
2. renseigner la demande ;
3. décrire clairement la situation ;
4. joindre les justificatifs autorisés ;
5. soumettre la demande ;
6. conserver le numéro de suivi.

## Suivi d’une réclamation

Pour suivre une réclamation, l’usager doit saisir :

- le numéro de la réclamation ;
- l’adresse électronique utilisée lors du dépôt ;
- ou le numéro de téléphone portable utilisé lors du dépôt.

## Numéro oublié

En cas d’oubli du numéro de suivi, l’usager peut contacter le service d’aide.

## Conseils pour rédiger une réclamation

La réclamation doit contenir :

- l’administration concernée ;
- la description précise des faits ;
- les dates ;
- les démarches déjà effectuées ;
- le préjudice subi ;
- la réponse souhaitée ;
- les justificatifs pertinents.

## Différence entre contact, information et réclamation

- Contact : demande générale ou orientation.
- Demande d’information : recherche d’une information précise.
- Réclamation : contestation ou signalement d’un problème.
- Observation : remarque sur la qualité d’un service.
- Suggestion : proposition d’amélioration.
