## Équipements de contrôle

Dans le cadre de la stratégie nationale de sécurité routière, plusieurs radars automatisés sont utilisés au Maroc.

Les équipements mentionnés comprennent notamment :

- 276 radars de contrôle de vitesse hors des périmètres urbains ;
- 204 radars contrôlant la vitesse et le respect du feu rouge dans les villes ;
- 72 radars de contrôle de la vitesse moyenne sur le réseau autoroutier.

## Infractions détectables

Les dispositifs peuvent notamment constater :

- les excès de vitesse ;
- le non-respect du feu rouge ;
- le franchissement d’une ligne continue ;
- la circulation sur une voie interdite ;
- plusieurs véhicules en infraction simultanément ;
- les différences de vitesse autorisée entre véhicules légers et poids lourds.

Ils peuvent également :

- identifier précisément le véhicule ;
- lire automatiquement la plaque d’immatriculation ;
- contrôler la vitesse moyenne sur un tronçon ;
- constater des infractions dans les deux sens de circulation.

## Étapes de traitement

Le traitement d’une infraction suit généralement les étapes suivantes :

1. détection du véhicule en infraction ;
2. prise d’une photographie ;
3. lecture de la plaque d’immatriculation ;
4. identification du propriétaire dans la base des certificats d’immatriculation ;
5. établissement du procès-verbal ;
6. validation et signature par l’agent compétent ;
7. notification du propriétaire ;
8. envoi éventuel d’un SMS si la personne utilise l’application Infractions Routières ;
9. paiement de l’amende, déclaration du conducteur ou dépôt d’une réclamation ;
10. transmission du procès-verbal au tribunal lorsqu’aucune action n’est effectuée dans le délai ;
11. mise à jour du solde de points lorsque l’infraction entraîne un retrait.

## Notification

La notification peut être envoyée :

- par e-Barkia ;
- par SMS lorsque l’utilisateur est inscrit au service correspondant.

## Délai de traitement par le citoyen

Le propriétaire dispose généralement de 30 jours à compter de la notification pour :

- payer l’amende ;
- déclarer le conducteur ;
- déposer une réclamation.

## Absence d’action

Lorsque le paiement, la déclaration ou la réclamation n’est pas effectué dans le délai, le procès-verbal peut être transmis à la juridiction compétente.

## Consultation en ligne

Un particulier peut consulter ses infractions sur la plateforme Infractions Routières.

Les professionnels peuvent utiliser le portail Tasrih Saeq pour consulter les infractions liées à leur parc de véhicules.

## Référence juridique

- Loi n° 52-05 portant Code de la route.
