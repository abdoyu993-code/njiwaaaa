## Dangers

La fatigue et la somnolence diminuent les capacités nécessaires à la conduite.

Elles peuvent provoquer :

- une baisse de concentration ;
- un ralentissement des réflexes ;
- une mauvaise coordination ;
- une mauvaise appréciation des distances ;
- une difficulté à prendre une décision ;
- une sortie de voie ;
- un endormissement ;
- une collision grave.

## Causes possibles

La fatigue peut être liée à :

- un manque de sommeil ;
- une longue journée de travail ;
- un trajet long et monotone ;
- la conduite de nuit ;
- un repas trop copieux ;
- une chaleur excessive dans l’habitacle ;
- une mauvaise aération ;
- la consommation d’alcool ou de stupéfiants ;
- certains médicaments provoquant une somnolence ;
- un problème de santé ;
- l’absence de pauses régulières.

## Signes d’alerte

Le conducteur doit s’arrêter lorsqu’il constate :

- des bâillements répétés ;
- des paupières lourdes ;
- des difficultés à garder les yeux ouverts ;
- une vision moins précise ;
- des raideurs dans le cou ou le dos ;
- un besoin fréquent de changer de position ;
- un engourdissement des jambes ;
- une difficulté à maintenir la trajectoire ;
- des oublis concernant les derniers kilomètres parcourus ;
- des réactions plus lentes.

## Périodes à risque

Les périodes naturellement associées au sommeil sont particulièrement dangereuses.

Les sources NARSA signalent notamment :

- la conduite tard le soir ;
- la conduite pendant la nuit ;
- la période entre environ 2 heures et 5 heures du matin ;
- le début de l’après-midi.

## Mesures de prévention

Avant le trajet, le conducteur doit :

1. dormir suffisamment ;
2. éviter de partir après une journée très fatigante ;
3. vérifier les effets secondaires des médicaments ;
4. éviter l’alcool et les stupéfiants ;
5. planifier les pauses ;
6. prévoir une durée de trajet réaliste.

Pendant le trajet, il est recommandé de :

- faire une pause au moins toutes les deux heures ;
- s’arrêter plus tôt lorsque les signes de fatigue apparaissent ;
- faire une courte sieste dans un endroit sûr ;
- partager la conduite lorsque cela est possible ;
- boire régulièrement de l’eau ;
- privilégier des repas légers ;
- maintenir une bonne ventilation dans l’habitacle ;
- éviter de conduire seul pendant un très long trajet.

## Conduite à tenir en cas de somnolence

Lorsque la somnolence apparaît, ouvrir la fenêtre, augmenter le volume de la musique ou boire du café ne constitue pas une solution suffisante.

La mesure la plus sûre est de :

1. quitter la circulation dans un endroit autorisé ;
2. immobiliser le véhicule ;
3. se reposer ;
4. reprendre la route uniquement après récupération.

## Principe essentiel

Le conducteur ne doit pas continuer uniquement parce qu’il pense être proche de sa destination.

La priorité doit rester d’arriver en sécurité.
