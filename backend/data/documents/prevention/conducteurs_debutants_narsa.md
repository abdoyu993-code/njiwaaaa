## Présentation

Le passage de l’apprentissage à la conduite autonome expose le nouveau conducteur à des situations réelles de circulation.

Le manque d’expérience, le stress et le désir de prouver ses capacités peuvent provoquer des décisions imprudentes.

## Respect du Code de la route

Le conducteur débutant doit notamment respecter :

- les limitations de vitesse ;
- les panneaux de signalisation ;
- les feux de circulation ;
- les priorités ;
- les distances de sécurité ;
- les règles de dépassement.

## Conduite calme

Il est conseillé de :

- éviter la précipitation ;
- ne pas réagir de manière impulsive ;
- anticiper les comportements des autres usagers ;
- rester prudent dans les zones urbaines ;
- prêter une attention particulière aux piétons et aux deux-roues.

## Choix de la voie

Pendant les premières périodes de conduite, il est recommandé :

- de rester sur une voie stable ;
- de privilégier la voie de droite lorsque les conditions le permettent ;
- d’éviter les changements de voie fréquents ;
- d’éviter les dépassements dangereux ;
- de ne pas réaliser inutilement des manœuvres complexes.

## Distance de sécurité

La distance de sécurité permet :

- d’anticiper un freinage ;
- de réagir à un arrêt brusque ;
- d’éviter une collision ;
- de garder le contrôle du véhicule.

## Concentration

Le conducteur doit éviter :

- le téléphone ;
- les messages ;
- les conversations trop distrayantes ;
- la manipulation du système multimédia ;
- toute activité qui détourne son regard ou son attention.

## Situations difficiles

En cas de mauvais temps, de conduite de nuit ou de circulation sur autoroute, il faut :

- réduire la vitesse ;
- renforcer la vigilance ;
- augmenter la distance de sécurité ;
- éviter les manœuvres brusques ;
- être particulièrement prudent dans les virages et près des passages piétons.

## Développement progressif de l’expérience

Durant les premiers mois, il est conseillé :

- de choisir des itinéraires connus ;
- de conduire à des horaires moins chargés ;
- d’éviter au début les situations très complexes ;
- d’augmenter progressivement la difficulté des trajets ;
- de reconnaître ses propres limites.

## Entretien du véhicule

Le conducteur débutant doit vérifier régulièrement :

- les pneus ;
- les freins ;
- les feux ;
- les niveaux des liquides ;
- l’état général du véhicule.

## Principe de confiance

La confiance ne signifie pas prendre davantage de risques.

Elle consiste à :

- évaluer correctement les dangers ;
- respecter ses limites ;
- prendre une décision adaptée ;
- conserver un comportement responsable.
