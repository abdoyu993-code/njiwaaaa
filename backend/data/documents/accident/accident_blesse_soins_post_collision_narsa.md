## Importance des premières minutes

Après un accident de la route, une intervention rapide et organisée peut :

- sauver des vies ;
- réduire la gravité des blessures ;
- éviter une aggravation de l’état des victimes ;
- accélérer leur prise en charge médicale.

Les services d’ambulance, les urgences médicales et les équipes de secours jouent un rôle essentiel dans la chaîne de survie.

## Conduite immédiate

Lorsqu’il y a des blessés :

1. sécuriser les lieux ;
2. appeler immédiatement les secours ;
3. fournir une localisation précise ;
4. indiquer le nombre de victimes ;
5. décrire leur état apparent ;
6. suivre les instructions données par les secours ;
7. ne pas déplacer une victime, sauf en cas de danger immédiat ;
8. ne pas donner à boire ou à manger à une personne gravement blessée ;
9. rassurer les victimes ;
10. attendre l’arrivée des professionnels.

## Informations à transmettre aux secours

Le témoin ou l’appelant doit indiquer :

- la localisation exacte ;
- le type de route ;
- le sens de circulation ;
- le nombre de véhicules ;
- le nombre de blessés ;
- la présence éventuelle d’un incendie ;
- la présence de carburant ou de matières dangereuses ;
- l’état de conscience des victimes ;
- les difficultés d’accès aux lieux.

## Prise en charge médicale

Après les soins d’urgence, certaines victimes peuvent avoir besoin :

- d’une hospitalisation ;
- d’une intervention chirurgicale ;
- de soins spécialisés ;
- d’une rééducation physique ;
- d’un suivi médical ;
- d’une réadaptation professionnelle ;
- d’un accompagnement psychologique.

## Réhabilitation

Les conséquences d’un accident peuvent continuer longtemps après la sortie de l’hôpital.

La réhabilitation peut inclure :

- la récupération de la mobilité ;
- le traitement des douleurs ;
- la réadaptation aux activités quotidiennes ;
- le retour au travail ;
- l’adaptation à un éventuel handicap ;
- le soutien social et familial.

## Soutien psychologique

Les victimes et leurs proches peuvent subir :

- un choc émotionnel ;
- de l’anxiété ;
- une peur de reprendre la route ;
- des troubles du sommeil ;
- un stress post-traumatique ;
- une perte de confiance.

Un accompagnement psychologique peut être nécessaire afin de faciliter le retour à une vie normale.

## Assurance

L’assurance peut intervenir notamment pour :

- la prise en charge de certains frais ;
- l’indemnisation des dommages ;
- l’accompagnement administratif ;
- la réparation ou le remplacement du véhicule ;
- l’indemnisation des victimes selon les responsabilités établies.

Le citoyen doit contacter son assureur et conserver les documents relatifs à l’accident.

## Documents utiles à conserver

Selon la situation :

- constat amiable ;
- procès-verbal des autorités ;
- coordonnées des témoins ;
- photographies prises sans gêner les secours ;
- certificat médical ;
- factures médicales ;
- ordonnances ;
- justificatifs de dépenses ;
- documents d’assurance ;
- preuves des dommages matériels.
