## Catégories de causes

Les accidents peuvent être liés à trois grandes catégories :

1. facteurs humains ;
2. conditions extérieures ou météorologiques ;
3. défaillances techniques.

Plusieurs facteurs peuvent se combiner dans un même accident.

## Facteur humain

La source NARSA présente l’erreur humaine comme le facteur dominant.

Les comportements à risque comprennent notamment :

- l’usage du téléphone au volant ;
- la consommation d’alcool ;
- la vitesse excessive ;
- la fatigue ;
- le non-port de la ceinture ;
- le non-port du casque ;
- le non-respect des distances de sécurité ;
- le manque d’attention ;
- les manœuvres dangereuses ;
- le non-respect des règles de circulation.

## Téléphone au volant

Le téléphone détourne l’attention du conducteur.

Il peut provoquer :

- un temps de réaction plus long ;
- une perte de concentration ;
- une mauvaise observation de la circulation ;
- une augmentation importante du risque d’accident.

## Alcool

La consommation d’alcool peut altérer :

- la perception ;
- la coordination ;
- le jugement ;
- les réflexes ;
- la capacité à évaluer les distances et la vitesse.

## Vitesse excessive

Une vitesse excessive :

- réduit le temps disponible pour réagir ;
- augmente la distance de freinage ;
- aggrave les conséquences d’une collision ;
- rend la maîtrise du véhicule plus difficile.

## Fatigue

La fatigue et la somnolence peuvent provoquer :

- une baisse de vigilance ;
- un ralentissement des réflexes ;
- une sortie de voie ;
- un endormissement ;
- une mauvaise appréciation des distances.

## Équipements de protection

Le non-port de la ceinture ou du casque augmente la gravité des blessures en cas d’accident.

## Distance de sécurité

Une distance insuffisante empêche le conducteur de réagir correctement lors d’un ralentissement ou d’un freinage brusque.

## Facteurs extérieurs

Les facteurs extérieurs peuvent inclure :

- la pluie ;
- le brouillard ;
- une mauvaise visibilité ;
- l’état de la chaussée ;
- la densité du trafic ;
- les obstacles ;
- les défauts techniques du véhicule.

Ces facteurs peuvent aggraver le risque, notamment lorsqu’ils sont combinés à un comportement dangereux.

## Prévention

Pour réduire les risques :

- respecter la vitesse ;
- ne pas utiliser le téléphone ;
- éviter l’alcool et les substances affectant la conduite ;
- dormir suffisamment ;
- utiliser la ceinture et le casque ;
- respecter les distances ;
- entretenir le véhicule ;
- adapter la conduite à la météo ;
- respecter le Code de la route.
