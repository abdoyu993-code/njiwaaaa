## Principe général

En cas de panne ou de crevaison, les priorités sont :

1. protéger les occupants ;
2. dégager la chaussée ;
3. rendre le véhicule visible ;
4. appeler une assistance ;
5. éviter un accident secondaire.

## Premières actions

Lorsque le conducteur constate une panne, il doit :

- garder le contrôle du véhicule ;
- activer les feux de détresse ;
- réduire progressivement la vitesse ;
- éviter les freinages brusques ;
- rejoindre le bas-côté ou un emplacement sécurisé ;
- ne pas bloquer l’accès des secours.

## Sortie du véhicule

Avant de sortir :

- enfiler le gilet réfléchissant ;
- vérifier la circulation ;
- sortir si possible par la portière opposée à la chaussée ;
- faire sortir les passagers du côté le moins dangereux.

Sur une autoroute ou une voie rapide, les occupants doivent se placer derrière la barrière de sécurité lorsque cela est possible.

## Signalisation

Le véhicule immobilisé doit être rendu visible grâce à :

- ses feux de détresse ;
- un triangle de signalisation ;
- un gilet réfléchissant ;
- éventuellement une lampe de poche la nuit.

Le triangle doit être placé seulement lorsque cette opération peut être effectuée sans mettre la personne en danger.

## Attente des secours

Une fois les personnes en sécurité :

- contacter l’assistance prévue par l’assurance ;
- contacter un dépanneur ;
- communiquer la position exacte ;
- indiquer le type de panne ;
- préciser le type de véhicule ;
- signaler si le véhicule bloque la circulation.

## Réparation sur place

Le conducteur ne doit pas tenter une réparation lorsqu’elle l’expose à la circulation.

Un changement de roue ou une autre intervention ne doit être réalisé que dans un emplacement suffisamment sécurisé.

## Sur autoroute

Sur autoroute ou voie rapide :

- ne pas rester sur la chaussée ;
- ne pas se placer devant ou derrière le véhicule ;
- se tenir derrière la barrière de sécurité ;
- ne pas traverser les voies ;
- appeler rapidement l’assistance ;
- attendre les professionnels dans une zone protégée.

## Comportements à éviter

Il faut éviter :

- de rester sur la route ;
- de réparer le véhicule dans une zone dangereuse ;
- d’installer le triangle si cela oblige à marcher sur une voie rapide ;
- de laisser les passagers à proximité de la circulation ;
- de pousser le véhicule sans protection ;
- de gêner les secours.
