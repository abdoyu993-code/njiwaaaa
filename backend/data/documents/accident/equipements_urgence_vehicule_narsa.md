## Triangle de signalisation

Le triangle de signalisation permet d’alerter les conducteurs qui approchent d’un véhicule immobilisé.

Il donne aux autres usagers davantage de temps pour :

- ralentir ;
- changer de voie ;
- éviter l’obstacle ;
- s’arrêter si nécessaire.

Il doit être placé à une distance suffisante pour être visible.

Sur autoroute, la source NARSA recommande une distance d’au moins 100 mètres lorsque son installation peut être effectuée sans danger.

## Gilet réfléchissant

Le gilet réfléchissant rend le conducteur et les passagers visibles :

- la nuit ;
- en cas de pluie ;
- en cas de brouillard ;
- lorsque l’éclairage est faible ;
- sur le bord d’une route.

Il doit être porté avant de sortir du véhicule.

## Trousse de premiers secours

Une trousse de premiers secours peut servir pour :

- les blessures légères ;
- les coupures ;
- la protection temporaire d’une plaie ;
- l’attente des secours.

Son contenu doit être vérifié régulièrement.

Les produits expirés ou endommagés doivent être remplacés.

## Lampe torche

La lampe torche permet :

- d’éclairer une zone sombre ;
- de voir autour du véhicule ;
- d’utiliser les équipements la nuit ;
- de signaler sa présence ;
- d’éviter de travailler dans l’obscurité.

## Câbles de démarrage

Les câbles peuvent aider à redémarrer un véhicule lorsque la batterie est déchargée.

Ils doivent être utilisés conformément aux recommandations du constructeur et sans créer de risque électrique.

## Matériel pour changer une roue

Le véhicule peut contenir :

- une roue de secours ;
- un cric ;
- une clé adaptée ;
- des gants ;
- un dispositif de sécurité.

Le conducteur ne doit changer une roue que dans une zone sécurisée.

## Vérification régulière

Le conducteur doit vérifier :

- la présence du triangle ;
- l’état du gilet ;
- la date des éléments de premiers secours ;
- les piles de la lampe ;
- l’état de la roue de secours ;
- la présence du cric et de la clé ;
- l’état des câbles de démarrage.

## Principe important

Un équipement de sécurité n’est utile que s’il est :

- présent ;
- accessible ;
- en bon état ;
- connu de l’utilisateur ;
- utilisé correctement.
